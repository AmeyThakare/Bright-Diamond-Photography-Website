# Bright Diamond Photography & Cinematography

An ultra-premium photography & cinematography portfolio website with interactive frame-by-frame 3D scroll experience, audio sound design, and haute visual aesthetics.

## 🚀 Getting Started

### Prerequisites
- Node.js (version 18 or newer recommended)
- npm or yarn

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```

### Preview Production Build
```bash
npm run preview
```

## ☁️ Deploying to Vercel

This repository is pre-configured for one-click deployment on [Vercel](https://vercel.com):

1. Go to **[vercel.com](https://vercel.com)** and log in.
2. Click **"Add New..."** > **"Project"**.
3. Import this repository: `Bright-Diamond-Photography`.
4. Vercel will automatically detect **Vite**:
   - **Framework Preset**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
5. Click **Deploy**! 🚀
